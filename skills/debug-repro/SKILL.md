# 调试与复现

核心纪律：**先拿到证据，再形成假设，一次只验证一个变量**。跳过复现直接改代码，等于蒙。

## 使用方法

**你会怎么说**
- `跑这个命令报错了`
- `这个测试偶发失败` / `线上偶尔 500`
- `为什么这里返回空`

**我需要什么**（缺了先问，不猜）
- **逐字**报错与堆栈（截图可以，但不要"大概报了个空指针"）
- 复现入口：命令、输入、操作序列、第几次出现
- 环境：OS/运行时/依赖版本、分支与 commit、工作区是否干净
- 最近改动：`git log --oneline -5`

**我会跑**
```bash
<失败的命令>                                   # 先复现，拿到原文
git log --oneline -10 -- <相关目录>
git log -S"<符号>" --oneline                   # 什么时候引入的
git bisect start && git bisect run <cmd>       # 跨多个提交的回归
```

**产出**：§6 格式——现象 / 复现 / 根因 / 修复 / 验证 / 未验证，复现必须"修复前失败、修复后通过"
**边界**：复现不出来就说"未复现"，只加可观测性和缩小范围，不盲改逻辑

## 1. 收集原始事实（不要转述，要原文）

- 完整报错与堆栈：**逐字**记录，包括退出码、错误类型、最后一段业务栈帧
- 环境：OS 与版本、运行时版本、依赖版本、分支与 commit、是否干净工作区
- 触发路径：什么输入、什么操作序列、第几次
- 频率与范围：必现/偶现、单机/多机、新装/升级后

缺哪一项就先补哪一项。**报错信息被"概括"过就失去价值。**

## 2. 复现

目标是最小、稳定、可重复的复现，不是"再试一次看看"。

1. 用最直接的入口跑（单测 > 脚本 > 手动点击 > 整个应用）
2. 拿到失败后**缩小输入**：删掉无关字段/行/步骤，直到删任何一处就不再失败
3. 缩小环境：换干净目录、默认配置、关掉缓存与并发
4. 用二分在**时间维度**上定位：代码通过/失败的两个版本之间 `git bisect run <cmd>`，或注释掉一半逻辑

复现不出来时，明确写出"未复现"，并列出下一步需要的环境差异（数据、权限、版本、时间窗口），不要假装修好了。

## 3. 定位

按性价比排序：

| 手段 | 适用 |
|---|---|
| 读堆栈最下面的业务帧 + 该行代码 | 所有崩溃，先看这里 |
| 打印/日志二分 | 逻辑走错分支、值不对 |
| `git log -S<符号>` / `git blame` | 最近才坏的 |
| `git bisect` | 跨越多个提交的回归 |
| 最小化复现脚本 | 并发、时序、内存 |
| 对比可用与不可用环境 | 依赖/配置/平台差异 |

假设必须可证伪，写成"如果 X 成立，关掉 X 后应当不再失败"。**一次只改一个变量**——同时改两处，结果无法归因。

常见陷阱（优先怀疑）：

- 空值/未定义在 None-like 与空串之间的区别
- 异步：await 缺失、竞态、事件顺序、缓存的旧值
- 平台差异：路径分隔符、大小写敏感性、换行、时区、locale、编码（Windows 尤其）
- 状态残留：上次运行的文件/缓存/全局单例
- 边界：0、空集合、单元素、超长、并发数 1

## 4. 修复

- 改**根因**，不是改症状（不要在调用方 try/catch 掩盖）
- 最小改动：不顺手重构、不顺手加功能
- 明确说出这个 bug 的**类别**：同类代码是否也需要改（grep 一遍）

## 5. 回归测试

修复必须配一个**在修复前会失败、修复后通过**的测试。写不出来 = 还没真正定位到根因。

- 测试名写清场景（"并发写入时不丢更新"），不要 `test_fix2`
- 偶发问题：跑 N 次或加人为延迟/时钟控制，否则不算覆盖

## 6. 输出格式

```
## 现象
<逐字报错 + 触发条件 + 频率>

## 复现
<最小复现步骤/脚本/命令，含实际输出>

## 根因
<哪一行、因为什么、为什么之前没暴露>

## 修复
<改动点：路径:行号 + 改法；影响面>

## 验证
- 复现脚本：修复前失败 / 修复后通过（贴关键输出）
- 回归测试：<测试名 + 位置>
- 同类排查：<grep 到的其他位置及结论>

## 未验证 / 遗留
<明确写出>
```

## 7. 边界

- 不改到"能跑"为止就收工：必须能解释为什么坏的
- 无法复现时，只做两件事：加可观测性（日志/断言）和缩小范围，不盲改逻辑
- 不删除或放宽既有测试来让结果变绿
